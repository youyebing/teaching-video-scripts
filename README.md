# 教学视频脚本系列

面向有编程基础的程序员的**计算机科普教学视频脚本**(口播逐字稿 + 分镜 + 素材清单),基于系统学习会话整理,可兼作软考备考资料。

## 系列结构

- **钩子**(制造认知冲突)→ **核心机制**(类比拆解)→ **拼装/推演**(完整示例)→ **收尾闭环 + 彩蛋 + 互动题**

## 彩蛋主题(通用思想)

- JVM 堆 / MySQL Buffer Pool ← 虚拟内存的"内存管理剧本"
- MySQL 主从复制 / 双机热备 / K8s 多副本 ← RAID 的"冗余剧本"
- JVM 卡表(Card Table)/ Linux 物理页 bitmap / MySQL 位图索引 ← 位示图的"资源账本剧本"
- 碎片整理 / 固态硬盘多队列 / 快递按楼栋排序 ← 磁盘调度的"排队重排术剧本"

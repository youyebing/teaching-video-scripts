# 教学视频脚本系列

面向有编程基础的程序员的**计算机科普教学视频脚本**(口播逐字稿 + 分镜 + 素材清单),基于系统学习会话整理,可兼作软考备考资料。

## 系列结构

- **钩子**(制造认知冲突)→ **核心机制**(类比拆解)→ **拼装/推演**(完整示例)→ **收尾闭环 + 彩蛋 + 互动题**
